🚀 Go-live checklist
1. Deploy to Render
Push this project to GitHub, then on render.com create a new Web Service pointed at your repo.
Set build command: npm install
Set start command: node server.js
2. Set environment variables on Render
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxx TWILIO_AUTH_TOKEN=your_auth_token TWILIO_PHONE_NUMBER=+1XXXXXXXXXX OPENAI_API_KEY=sk-proj-xxxxxxxx BASE_URL=https://your-app.onrender.com PORT=3000
3. Point Twilio at your app
In Twilio Console → Phone Numbers → your number:
• Voice webhook: https://your-app.onrender.com/twilio/inbound (HTTP POST)
• Status callback: https://your-app.onrender.com/twilio/status
4. Test the connection
Call your Twilio number from any phone. Marina should answer and start the conversation.
5. Connect buzz360.io webhook
In BotSailer, add a webhook action that POSTs to /api/trigger when a customer opts in for a call.
